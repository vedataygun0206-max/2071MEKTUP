# 2071 Mektup

Bugünü mühürle, geleceğe bırak.

İlk prototip: zaman kapsülü oluşturma, açılış tarihi, kilitleme, yıllık arşiv ve kamuya açık/açılmış mektuplar için temel proje iskeleti.

## İlk sürüm hedefleri
- Kullanıcı ve kapsül modeli
- 1/5/10/25/45 yıl veya özel tarih
- Kilitlenmiş kapsülün açılış tarihinden önce okunamaması
- Yıllık kayıtlar
- Not, mektup, fotoğraf, ses/video ve belge ekleri
- Özel / aile / kamu görünürlüğü
- Açılan kamu mektupları arşivi
- Sunucu zamanı ile doğrulanan geri sayım
- Dışa aktarılabilir arşiv

## Güvenlik ilkesi
Banka/kasa parolaları gibi kritik sırlar düz metin saklanmayacak. Güvenlik soruları kimlik doğrulama için, gerçek sırlar ise ayrı şifreli emanet mekanizmasıyla ele alınacak.
